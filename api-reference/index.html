Proton API reference

Every endpoint Proton's own web clients call, with its parameters and response shape - the API proton api sends requests to.

Proton publishes no API documentation, so this is generated from the source of their own web clients and regenerated weekly, which is what makes it follow the endpoints they actually call.proton api is what sends a request to any of it, with your session and your headers already attached.

The file behind this page is served as it is at /openapi.yaml, for a code generator or an HTTP client to read.
